# Дополнение отправленного заказа
Обновление поверх установленного orders-update. Новый проект создавать не нужно.
1. Положите папку orders-supplement-update в существующий проект рядом с package.json.
2. Выполните sql/07_supplements.sql в SQL Editor Supabase. Старые SQL повторять не нужно.
3. В терминале проекта: node orders-supplement-update/install.cjs
4. Запустите npx expo start -c. Для установленного APK потребуется новая сборка.

В отправленном заказе появится «Дополнить заказ». Вводите только дополнительное количество. До отправки можно закрыть форму без изменений; черновик дополнения не сохраняется при закрытии приложения. Минимумы проверяются по исходному заказу и дополнению вместе, отдельно для каждого поставщика. Уже заказанные товары сохраняют прежнюю цену, новые — текущую цену каталога. Сервер повторно проверяет условия.

После подтверждения дополнения запрещены на сервере. Если администратор открыл старую версию, подтвердить её после дополнения невозможно: нужно обновить список. Исходный состав сохраняется в истории; администратор видит добавления, сводка — обновлённый итог без двойного счёта. После ошибки сети обновите заказ: повтор со старой версией не добавляет товары второй раз.

Установщик меняет только четыре файла заказов, создаёт резервную копию и отказывается перезаписывать незнакомые изменения. Другие разделы не меняет.
Проверены TypeScript, lint и сценарии PostgreSQL в локальной тестовой базе. На вашем телефоне и в рабочей Supabase обновление пока не выполнялось.
