# Обновление разделов ТТК

Верхние вкладки теперь соответствуют листам исходной таблицы (поле source_sheet). Статусы «На ввод» и «На вывод» остаются цветными отметками на карточках. Поиск работает внутри выбранного раздела; «Все разделы» ищет по всему доступному каталогу.

## Установка в текущий проект

1. Остановите Expo в терминале: Ctrl+C.
2. Распакуйте архив и поместите папку ttk-sections-update внутрь текущей папки BarManager, рядом с package.json.
3. В терминале VS Code из корня BarManager выполните:

```sh
node ttk-sections-update/install.cjs
npx expo start -c
```

Установщик заменяет только четыре файла: src/app/recipes/index.tsx, src/lib/recipes.ts, src/lib/recipe-model.ts и src/lib/recipe-sections.ts. Копии существующих файлов сохраняются в ttk-update-backups с расширением .bak. Повторный запуск безопасен. Нормы хранения, главная, заявки, настройки подключения и остальные экраны не изменяются. Изменения, самостоятельно внесённые в эти четыре файла, следует сопоставить с резервной копией.

SQL выполнять не нужно. Используется существующее поле recipes.source_sheet, с резервным отображением имени категории. Скрытые позиции исключаются для обычного пользователя; защита данных на сервере зависит от ранее настроенных правил RLS Supabase.

Разделы формируются только по импортированным доступным рецептурам. Если пока загружена только «Сезонка зима 2026», появится только этот раздел и «Все разделы». Остальные листы и фотографии необходимо импортировать отдельно — архив не добавляет данные в Supabase.

Проверено: TypeScript, ESLint, 6 тестов группировки, поиска и фильтрации скрытых позиций. На реальном телефоне и с вашей действующей базой это обновление пока не проверялось.
